# Support

FinanceTracking.app is a maintainer-led, self-hosted project. Support is best effort and does not include an uptime, response-time, or resolution-time guarantee.

## Start with the documented path

- [Local trial and repository guide](README.md#quick-start)
- [Production self-hosting](README.md#self-hosting)
- [Hosted user documentation](https://financetracking.app/docs/)
- [Public support guide](https://financetracking.app/support/)
- [Current releases](https://github.com/taimoorq/expense_tracker/releases)

Support is focused on the latest stable release, the documented Docker Compose paths, the published GHCR image, and unmodified source checkouts that follow the repository instructions.

## Choose the right route

- **Reproducible product bug:** use the [bug report form](https://github.com/taimoorq/expense_tracker/issues/new?template=bug_report.yml).
- **Installation or update problem:** use the [setup help form](https://github.com/taimoorq/expense_tracker/issues/new?template=setup_help.yml).
- **Workflow feedback or feature idea:** use the [product feedback form](https://github.com/taimoorq/expense_tracker/issues/new?template=product_feedback.yml).
- **Suspected vulnerability:** follow [SECURITY.md](SECURITY.md) and report it privately. Do not open a public issue.
- **Commercial permission:** follow [COMMERCIAL-LICENSING.md](COMMERCIAL-LICENSING.md).

## Before opening a public issue

1. Confirm the issue still occurs on the latest stable release.
2. Search existing issues for the symptom or error message.
3. Include the app version, host architecture, browser, deployment method, relevant configuration names, and exact reproduction steps.
4. Include the smallest useful log excerpt and explain what you expected to happen.
5. Replace account names, transaction descriptions, amounts, email addresses, hostnames, and other personal details with fabricated values.

Never post passwords, cookies, Rails credentials, database URLs, private keys, complete environment files, bank exports, database dumps, or real financial screenshots.

## Support boundaries

The project can help explain documented behavior and investigate reproducible application defects. It cannot operate your server, guarantee compatibility with every reverse proxy or bank CSV, restore an untested backup, support every fork, or provide accounting, tax, legal, investment, or financial advice.

Questions about a custom commercial deployment can be discussed through the commercial-permission route. Contribution terms are being formalized separately; discuss a substantial upstream change before relying on its acceptance.
